# ⏳ Habit Timer（習慣化タイマー＆相棒キャラ育成アプリ）

毎日のタスク達成と習慣化をサポートする、モバイルPWA対応のタイマーアプリです。

## 🌐 クラウド公開URL
- **https://kouluun2.github.io/habit-timer/**
  - スマホのブラウザ（Safari / Chrome）から「ホーム画面に追加」すると、フルスクリーンのアプリとして利用できます。

## ✨ 主な機能
- **マルチ時間タイマー**: 数分〜最大99時間59分まで設定可能（バックグラウンドでも正確なタイムスタンプ計算）
- **定番アラーム音＆振動**: メディア再生セッション（`playback`）によりマナーモード中もスピーカー再生に対応
- **キャラ図鑑＆広場**: 全タスク完了による連続達成日数に応じて6種類のキャラクターがアンロック
- **過去のデータ**: `週`・`月`・`年`・`全体` の4期間対応折れ線グラフと、タスク別の累計時間・完了履歴
- **アップデート耐性3重保存**: `localStorage` + `IndexedDB` + `CacheStorage` によりアップデート後もデータを自動保持

## 🛠️ 開発コマンド

```bash
# 開発サーバー起動
npm run dev

# 本番ビルド
npm run build
```
